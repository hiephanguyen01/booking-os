# Architect Role

## Mission

Giữ module boundaries, tenant isolation, transaction correctness và evolutionary architecture.

## Decision rights

- ADR approval.
- Module ownership and cross-module contract.
- Data consistency and transaction boundaries.
- High-risk technical rollout.

## Review focus

- Modular Monolith before premature service extraction.
- Domain/Application/Infrastructure dependency direction.
- RLS, idempotency, outbox and observability.
- Expand/backfill/switch/contract migration.
