## Responsibilities

- **Accountable owner:** owns final product, architecture, risk, and escalation decisions.
- **Domain owner:** provides day-to-day technical and domain stewardship after assignment.
- **Contributors and reviewers:** implement or review work without receiving ownership automatically.

Identity, Sessions, Memberships, and Authorization are explicitly assigned for Sprint 1B operations and recovery. A future ownership transfer updates this document and review routing; it does not weaken the current security or database boundaries.
