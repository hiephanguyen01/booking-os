## Responsibilities

- **Accountable owner:** owns final product, architecture, risk, and escalation decisions.
- **Domain owner:** provides day-to-day technical and domain stewardship after assignment.
- **Contributors and reviewers:** implement or review work without receiving ownership automatically.

Assigning a future domain owner updates this document and the review routing for that domain. It does not require an architecture change.
